# SYSTEM-FOR-EVALUATING_PUBLIC-SPACES_SEA
## Система оценки общественных пространств у водных объектов
Данный алгоритм оценки ориентирован на условия прибрежных морских городов. В основе алгоритма – оценка общественных пространств, отражающая климатическую адаптивность, взаимодействие с акваторией, функциональную гибкость, устойчивость и безопасность, а также социально-пространственную эффективность.
### Принцип работы
1. Формируется векторный слой с корректной структурой атрибутивнх полей. Для оцениваемого пространства предусматриваются поля: id, name, сценарий – заполняется код климатического сценария: 1 – Север, 2 – Юг, 3 – Запад, 4 – Восток ; далее создаются поля параметров: А_сезон, А_ветер и тд. 
2. В соотвествии с [Таблицы интерпретаций](Таблицы%20интерпретаций) запоняются значения параметров полей. 
3. Запускается [Модель](Расчет%20I_A). Алгоритм вычисляет индекс эффективности I_A и визуаизирует резуьтаты.
